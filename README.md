# 前庭感覚バランスリハビリ運動ガイド

良性発作性頭位変換症（BPPV）の頭位変換法（エプリー法・シーモント法・Brandt-Daroff体操）をSVGイラストと工程説明で図解するアプリです。めまい症状スコアのトラッキングと週次改善グラフも備えています。

## 機能
- エプリー法：4ステップ図解（患側向き座位〜起き上がり）
- シーモント法：3ステップ図解
- Brandt-Daroff体操：5ステップ日常体操ガイド
- 各ステップのSVG体位図・手順説明・カウントダウンタイマー
- めまい強度・吐き気スコア（0〜10）の日次記録
- 週次改善グラフ（SVG折れ線・2指標同時表示）
- 耳石の仕組み説明パネル
- 安全警告・医療免責事項の明示
